# Fayda ID Card Converter Telegram Bot 🇪🇹🤖

A privacy-focused, automated Telegram Bot built in Python that takes photos of the **Front**, **Back**, and **QR code** of an Ethiopian National Digital ID (Fayda) and compiles them automatically into a clean, standardized, and printable digital card layout.

---

## 🚀 Features
* **Simultaneous Upload:** Users can select all 3 required photos from their gallery and send them together as a single album.
* **Auto-Detection Layer:** Automatically identifies which uploaded photo is the Front, Back, or QR code regardless of selection order.
* **Instant Data Privacy Shredding:** Automatically and securely deletes all user-submitted ID photos from the server storage immediately after processing.
